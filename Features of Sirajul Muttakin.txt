1. EXECUTIVE SUMMARY & TECH STACK
================================================================================
DreamPC is an enterprise-grade, conversational PC hardware marketplace built on top of the Laravel MVC framework. It combines standard e-commerce features with an Automated Hardware Compatibility & Rules Engine and an NLP AI Hardware Assistant (powered by Google Gemini API with smart algorithmic fallback).

Core Technologies Used:
- Backend Framework: PHP 8.2+ with Laravel 11.x (MVC Architecture, Service Layer Pattern)
- Database: MySQL with Eloquent ORM, normalized relations, and foreign key constraints
- Frontend & Styling: Blade Templating Engine, Tailwind CSS (Custom extended design system with Dark/Light mode), Vanilla JavaScript (AJAX / Fetch API, real-time DOM hydration, CSS3 micro-animations)
- Hardware Analysis & Calculations: Custom algorithmic services (CompatibilityEngine, BuildCostCalculator, BudgetOptimizerService, HardwareRecommendationEngine, SpecExtractorService)
- Artificial Intelligence: Google Gemini 1.5 Flash API with JSON structured schema output + local intelligent recommendation engine
- Testing & Quality Assurance: PHPUnit Automated Feature & Unit Test Suite

2. END-TO-END SYSTEM WORKFLOW & ARCHITECTURE
================================================================================
The DreamPC platform operates as an integrated pipeline across 6 distinct layers:

1. Data Layer:
   Products and their key-value technical specifications (e.g., socket: AM5, memory_type: DDR5, tdp: 120W, gpu_length: 304mm, supported_form_factors: ATX) are stored in the database. SpecExtractorService normalizes these into standard key-value maps.

2. Recommendation & AI Layer:
   Users can interact via the Natural Language Processing Chat Interface. The system parses budget constraints, gaming resolutions, brand preferences (Intel vs. AMD, NVIDIA vs. Radeon), and hardware queries. It queries Gemini API or the local HardwareRecommendationEngine to generate full, 7-component compatible PC builds (CPU, Motherboard, RAM, GPU, Storage, PSU, Case).

3. Validation & Rules Engine Layer:
   Every build configuration is passed through CompatibilityEngine to guarantee 100% mutual hardware compatibility (CPU Socket match, RAM Generation match, Case Form Factor clearance, PSU TDP headroom) and detect bottleneck/clearance conflicts before purchase.

4. Cost Calculation & Optimization Layer:
   BuildCostCalculator aggregates subtotals, applies regional taxes, computes dynamic shipping based on component counts, and tracks item percentage cost allocations. If a build exceeds budget limits, BudgetOptimizerService automatically identifies non-critical parts (Storage, Case, Cooler, RAM) and swaps them for cost-effective alternatives.

5. Cart & Batch Execution Layer:
   Users can add individual components or export entire 7-component AI builds to their cart in a single atomic action. Real-time AJAX controls allow quantity edits, item deletions, and alternative component swaps.

6. Checkout, Discount & Historical Snapshot Layer:
   The checkout engine applies promotional discount coupons, allows users to choose between Express Delivery or In-Store Pickup with date scheduling, creates orders, and generates immutable JSON specification snapshots for permanent warranty and one-click reordering.

FEATURE 6: AUTOMATED HARDWARE COMPATIBILITY ENGINE
--------------------------------------------------------------------------------
- Primary File: app/Services/CompatibilityEngine.php
- Method: checkCompatibility(array $productIds): array
- Purpose: Acts as the core verification brain of DreamPC. It inspects all components in a user's build and determines whether they are physically and electronically compatible.

Verification Rules Implemented:
1. CPU Socket vs. Motherboard Socket:
   - Compares the CPU's socket (e.g. AM5 or LGA1700) with the Motherboard socket.
   - If they differ, the build is flagged as incompatible with an explicit error:
     "CPU Socket (AM5) does not match Motherboard Socket (LGA1700)."

2. RAM Memory Generation vs. Motherboard Slot Standard:
   - Verifies memory generation (DDR4 vs DDR5).
   - Prevents fatal mismatch errors where DDR4 is slotted onto a DDR5-only board (e.g. AMD AM5 platform).

3. Motherboard Form Factor vs. Chassis Dimensions:
   - Inspects the motherboard's form factor (ATX, Micro-ATX, Mini-ITX) against the case's supported_form_factors list.
   - If an ATX motherboard is placed into a Micro-ATX-only case, flags an incompatibility warning.

4. Power Supply (PSU) Output vs. System Total TDP Headroom:
   - Extracts TDP from each component (CPU TDP, GPU TDP, Motherboard, etc.).
   - Computes Total TDP and applies an industry safety multiplier: Total TDP * 1.25.
   - If the installed PSU wattage is less than the calculated minimum, warns the user of possible shutdown risks during transient voltage spikes.

FEATURE 8: HARDWARE CONFLICT & BOTTLENECK DETECTOR
--------------------------------------------------------------------------------
- Primary File: app/Services/CompatibilityEngine.php
- Method: detectBottlenecksAndConflicts(array $productIds): array
- Purpose: Extends basic compatibility into advanced structural clearance validation and performance bottleneck detection.

Rules & Diagnostics Implemented:
1. GPU Length Clearance vs. Case Maximum Clearance:
   - Extracts the GPU length in millimeters (e.g., RTX 4090 = 304mm).
   - Extracts the case max_gpu_clearance (e.g., 360mm).
   - If gpu_length > max_gpu_clearance, returns a physical conflict alert with a recommendation to choose a larger case or shorter graphics card.

2. CPU Cooler Height vs. Case Width Limit:
   - Compares CPU cooler height (mm) against case max_cooler_height (mm) to ensure the side glass panel closes properly.

3. CPU-GPU Performance Bottlenecks:
   - Detects extreme pairings (e.g., Flagship GPU like RTX 4090 paired with an entry-level Core i3 or Ryzen 3).
   - Flags a bottleneck advisory explaining that the CPU will bottleneck the GPU during 1440p/4K high-refresh gaming and content creation.

4. PCIe Bus Generation Bandwidth Bottlenecks:
   - Checks if a PCIe Gen 4.0 or Gen 5.0 GPU is paired with an older PCIe Gen 3.0 motherboard, advising the user of reduced bandwidth transfer speeds.

FEATURE 7: REAL-TIME BUILD COST CALCULATION ENGINE
--------------------------------------------------------------------------------
- Primary File: app/Services/BuildCostCalculator.php
- Primary Controller: app/Http/Controllers/BuildController.php (calculateCost method)
- Endpoint: /api/build/calculate-cost (GET / POST)
- Purpose: Real-time price aggregation engine that computes component costs, percentage contributions, taxes, and shipping rates.

Calculation Logic:
1. Subtotal Aggregation:
   - Sums unit prices across all product IDs in the build (supporting duplicates).
2. Regional Tax Calculation:
   - Computes standard 5% sales tax: round(subtotal * 0.05, 2).
3. Dynamic Shipping Model:
   - Implements tiered shipping logistics: Base fee of $15.00 + $2.00 per additional hardware component. (0 components = $0.00).
4. Component Cost Contribution Breakdown:
   - Calculates the exact percentage each component contributes to the total price:
     percentage_contribution = round((item_price / subtotal) * 100, 2)
   - Enables visual representation in progress bar analytics.

FEATURE 9: AI-DRIVEN BUDGET OPTIMIZATION & ALTERNATIVE MATCHER
--------------------------------------------------------------------------------
- Primary File: app/Services/BudgetOptimizerService.php
- Method: optimizeBuild($currentBuild, float $targetBudget): array
- Purpose: When a custom PC build exceeds the user's budget ceiling, this service automatically optimizes the component list by safely downgrading non-essential parts while protecting core CPU and GPU gaming performance.

Optimization Algorithm:
1. Identifies the budget delta: delta = currentTotal - targetBudget.
2. If delta <= 0, marks build as within_budget.
3. Filters flexible categories: ['storage', 'case', 'cooler', 'ram', 'psu'] (never downgrades CPU or GPU first).
4. Sorts flexible components by highest price descending to achieve maximum savings rapidly.
5. For each flexible component, queries the database for the closest cheaper in-stock alternative in the same category.
6. Substitutes the component, records the savings, decrements delta, and tracks an audit log of all swapped alternatives.

```php
public function checkCompatibility(array $productIds): array
{
    $context = $this->specExtractor->getSystemSpecsContext($productIds);
    $components = $context['components'];
    $isCompatible = true;
    $incompatibilities = [];

    // Socket match
    if (isset($components['cpu'], $components['motherboard'])) {
        $cpuSocket = $components['cpu']['specs']['socket'] ?? null;
        $moboSocket = $components['motherboard']['specs']['socket'] ?? null;
        if ($cpuSocket && $moboSocket && strtolower($cpuSocket) !== strtolower($moboSocket)) {
            $isCompatible = false;
            $incompatibilities[] = "CPU Socket ({$cpuSocket}) does not match Motherboard Socket ({$moboSocket}).";
        }
    }

    // RAM generation match
    if (isset($components['ram'], $components['motherboard'])) {
        $ramType = $components['ram']['specs']['ram_type'] ?? null;
        $moboRamType = $components['motherboard']['specs']['memory_type'] ?? null;
        if ($ramType && $moboRamType && strtolower($ramType) !== strtolower($moboRamType)) {
            $isCompatible = false;
            $incompatibilities[] = "RAM Type ({$ramType}) does not match Motherboard supported RAM ({$moboRamType}).";
        }
    }

    // Power headroom (TDP * 1.25)
    $totalTdp = 0;
    foreach ($components as $component) {
        $tdpStr = $component['specs']['tdp'] ?? null;
        if ($tdpStr && preg_match('/(\d+)/', $tdpStr, $m)) {
            $totalTdp += (int)$m[1];
        }
    }
    if (isset($components['psu'])) {
        $psuWattage = (int)($components['psu']['specs']['wattage'] ?? 0);
        $requiredWattage = ceil($totalTdp * 1.25);
        if ($requiredWattage > $psuWattage) {
            $isCompatible = false;
            $incompatibilities[] = "PSU Wattage ({$psuWattage}W) is lower than recommended ({$requiredWattage}W for {$totalTdp}W TDP).";
        }
    }

    return ['is_compatible' => $isCompatible, 'incompatibilities' => $incompatibilities];
}
```

public function calculateFullBreakdown(array $productIds): array
{
    $products = Product::whereIn('id', $productIds)->get()->keyBy('id');
    $subtotal = 0.0;
    foreach ($productIds as $id) {
        if (isset($products[$id])) {
            $subtotal += (float)$products[$id]->price;
        }
    }

    $tax = round($subtotal * 0.05, 2);
    $shipping = count($productIds) > 0 ? round(15.00 + ((count($productIds) - 1) * 2.00), 2) : 0.0;
    $total = round($subtotal + $tax + $shipping, 2);

    $items = [];
    foreach ($productIds as $id) {
        if (isset($products[$id])) {
            $price = (float)$products[$id]->price;
            $percentage = $subtotal > 0 ? round(($price / $subtotal) * 100, 2) : 0;
            $items[] = [
                'product_id' => $id,
                'name' => $products[$id]->name,
                'price' => $price,
                'percentage_contribution' => $percentage,
            ];
        }
    }

    return [
        'subtotal' => round($subtotal, 2),
        'tax' => $tax,
        'shipping' => $shipping,
        'total' => $total,
        'items' => $items,
    ];
}

--- [3] BudgetOptimizerService.php (Extract) ---
```php
public function optimizeBuild($currentBuild, float $targetBudget): array
{
    $build = is_array($currentBuild) ? collect($currentBuild) : clone $currentBuild;
    $delta = $build->sum('price') - $targetBudget;
    $alternativesUsed = [];
    $totalSavings = 0;

    if ($delta <= 0) {
        return ['optimized_build' => $build, 'total_savings' => 0, 'status' => 'within_budget'];
    }

    $flexible = $build->filter(function ($p) {
        $slug = strtolower(optional($p->category)->slug ?? '');
        return in_array($slug, ['storage', 'case', 'cooler', 'ram', 'psu']);
    })->sortByDesc('price');

    foreach ($flexible as $p) {
        if ($delta <= 0) break;
        $cheaper = Product::where('category_id', $p->category_id)
            ->where('price', '<', $p->price)
            ->where('stock_quantity', '>', 0)
            ->orderBy('price', 'desc')
            ->first();

        if ($cheaper) {
            $savings = $p->price - $cheaper->price;
            $build = $build->map(fn($item) => $item->id === $p->id ? $cheaper : $item);
            $alternativesUsed[] = ['original' => $p->name, 'replacement' => $cheaper->name, 'savings' => $savings];
            $delta -= $savings;
            $totalSavings += $savings;
        }
    }

    return [
        'optimized_build' => $build,
        'total_savings' => $totalSavings,
        'alternatives_used' => $alternativesUsed,
        'status' => $build->sum('price') <= $targetBudget ? 'optimized_successfully' : 'partially_optimized',
        'new_total' => $build->sum('price')
    ];
}
```
